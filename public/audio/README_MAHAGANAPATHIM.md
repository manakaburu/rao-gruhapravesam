# Optional local Mahaganapathim violin recording

The requested A. Kanya Kumari `Maha Ganapathim (Instrumental)` commercial recording
is NOT bundled, because a free license allowing public website redistribution
could not be verified.

To use your own appropriately licensed violin MP3:
1. Obtain permission to reproduce and publicly host the **specific recording**.
2. Copy your MP3 to `public/audio/mahaganapathim-violin.mp3` (exact filename).
3. Restart the dev server if needed and reload. The music control will prefer that
   file automatically; otherwise it plays the bundled original composition.

The app attempts audible autoplay when loaded. Modern browser autoplay rules may
block this; in that case guests must tap the music control to hear it.

The default `rao-auspicious-welcome-original.mp3` is an independent original
instrumental, NOT the commercial recording or a rendition of that melody.
