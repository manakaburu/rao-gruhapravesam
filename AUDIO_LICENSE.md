# Bundled audio — originality & usage

The file `public/audio/rao-auspicious-welcome-original.mp3` is an **original, newly synthesized instrumental arrangement** prepared for this invitation. It is **NOT** “Mahaganapathim (Instrumental)” by A. Kanya Kumari or the SoundCloud recording linked in the project. It contains no sampled tracks, downloaded audio, or reproduced non-public-domain melodies. It is included so the site is functional offline and may be hosted as part of this project.

The user may copy, distribute and modify the audio file as part of their invitation website, including public hosting. No rights to third-party recordings are transferred. To replace it with the exact SoundCloud recording, obtain the separate rights holder's authorization and update the player source. The app attempts autoplay but must respect browser restrictions; when blocked, guests press Play. The local original loops and fades on play/pause.
